Architecture map

Foundation versus custom systems

Stable middleware provides locomotion, statistics and presentation. Custom systems coordinate the game-specific behavior.

Layer 1 · Foundation

Industry middleware

  • ARPG MotorStatistics, HP/MP, damage, elements and weaknesses.
  • Invector3D locomotion, physics, collisions, camera and core combat.
  • KoreographerDSP-time music synchronization for timed actions.
  • Adventure CreatorScene logic, global data and state management.
  • DestroyIt + SALSADestructible environments and procedural lip-sync.
Layer 2 · Custom

Game-specific systems

  • Turbo DriverDeckManager, CardSlot3D, CardTemplate, hand resources and hot-swappable combat sets.
  • DirectorEpisode structure, cinematics, limited decisions and cross-episode consequences.
  • Love / HateLong-term character affinity memory.
  • Integration bridgesAdapters connect combat, state, camera, animation and narrative tools without reloading the scene.
Combat flow map

Timing, response and reward

TaekwonFlow turns synchronized player input into animation, combat feedback and meta-game rewards.

  1. Synchronized inputCompare the player action against a DSP-timed Koreographer marker.
  2. Timing verdictOn-time input triggers the special animation or perfect parry; off-time input falls back to the standard Invector action.
  3. Performance modifierAccuracy adjusts damage and the encounter rating.
  4. Meta rewardSynchronized finishers and a high show rating generate bonus coins.
  5. Deck updateDeckManager receives the reward and updates the card economy.

Implemented through bridges between Koreographer, Invector, Adventure Creator and the custom gameplay layer.
