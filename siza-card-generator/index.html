Efectos estructurados

Agregue efectos con selectores. Cada tipo define sus propios parámetros y el editor se amplía automáticamente desde el catálogo de card-effects.js.

Edición batch

Formato: una lista JSON de objetos con id. Puede usar attack/defense en batch; el runtime sigue recibiendo sus valores compatibles. Si el batch no incluye arte, Battle Sprite, template o sus transformaciones, se conservan los ajustes manuales ya guardados.
Template Builder modular. Cada pieza usa el mismo canvas transparente 1500×2100. El Builder sólo ensambla apariencia; cristales, texto, stats, ilustración y Battle Sprite siguen siendo datos de la carta.
