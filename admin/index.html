Visual Portfolio Editor

The old browser folder-picker editor has been removed. This version runs locally on your PC, edits the actual portfolio visually, keeps image bytes untouched, and publishes with your existing Git login. No GitHub token field.

Download / Open Visual Editor Open Illustration Portfolio Open 3D Portfolio
1. Run itDouble-click OPEN_PORTFOLIO_EDITOR.cmd. It updates or clones the portfolio automatically.
2. Edit visuallyThe editor opens in your browser at 127.0.0.1:8765. Drag images in, replace, delete and reorder them.
3. PublishPress Publish changes inside the editor. It commits and pushes the illustration changes to main.
The editor server binds only to 127.0.0.1, so the editing interface itself is local to your computer. The public /admin/ page is only the launcher.
