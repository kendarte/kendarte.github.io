Procedural race simulation

Horse Racer

A fully automated 1v1 simulation pipeline built in Unity. One race ID selects the competitors and finish condition, configures duration-based movement, presents changing camera shots and records the completed result.

What I built.

Concrete systems inside the automated production pipeline.

01

Outcome matrix

A bounded ID maps to one of 45 horse pairings and one of seven timing outcomes, producing 315 repeatable races.

02

Duration-based movement

Each competitor measures its waypoint lane and converts an assigned finish duration into acceleration, speed and animation pacing.

03

Cinematic direction

Progress-driven shot presets, separation-aware framing, FOV transitions and a fixed photo-finish setup create readable coverage.

04

Automated capture

Unity Recorder generates deterministic filenames, stops on the finish event and advances to the next race configuration.

System flow

From ID to exported race.

  1. 01Map ID

    Select a pairing and finish condition.

  2. 02Configure

    Activate two competitors and assign lane durations.

  3. 03Simulate

    Convert path distance and time into movement.

  4. 04Present

    Direct cameras and display the result.

  5. 05Record

    Export the MP4 and advance the batch.
