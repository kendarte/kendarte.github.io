Case study

One system instead of 315 hand-built races.

An independently developed production prototype designed to generate repeatable race content and record it with minimal manual intervention.

Problem

Scale outcomes without duplicating scenes.

Ten horses produce 45 unique pairings, and seven finish conditions expand that matrix to 315 results. Authoring and recording every variation manually would be slow and error-prone.

Constraints

Movement, presentation and capture had to agree.

Two independent lanes, exact finish timing, changing camera coverage, winner presentation and Unity Recorder all needed to follow the same race definition.

Decision

Make the race ID the shared source of truth.

A bounded ID selects the pairing and outcome. Target duration drives movement, while the same race state informs the camera director, result UI, deterministic filename and batch progression.

Contribution

Solo systems and tools development.

I designed and programmed the race orchestration, movement model, camera director, editor tooling, track generation, presentation logic and automated recording workflow.

Verified result

A playable Windows demo and complete automated race on video.

The itch.io build provides a downloadable Windows demo, while the main video shows the working pipeline from configured competitors through duration-based racing, dynamic camera changes and the final result. The implementation supports 315 reproducible configurations and is documented in the public code repository.

Responsibility

What I built.

Concrete systems inside the automated production pipeline.

01

Outcome matrix

A bounded ID maps to one of 45 horse pairings and one of seven timing outcomes, producing 315 repeatable races.

02

Duration-based movement

Each competitor measures its waypoint lane and converts an assigned finish duration into acceleration, speed and animation pacing.

03

Cinematic direction

Progress-driven shot presets, separation-aware framing, FOV transitions and a fixed photo-finish setup create readable coverage.

04

Automated capture

Unity Recorder generates deterministic filenames, stops on the finish event and advances to the next race configuration.

System flow

From ID to exported race.

  1. 01Map ID

    Select a pairing and finish condition.

  2. 02Configure

    Activate two competitors and assign lane durations.

  3. 03Simulate

    Convert path distance and time into movement.

  4. 04Present

    Direct cameras and display the result.

  5. 05Record

    Export the MP4 and advance the batch.
