How I work

A practical path from bug report to stable hand-off.

The goal is not clever code. The goal is a system another person can test, understand and continue.

  1. 01 / AUDIT

    Map ownership

    Reproduce failures, identify competing authorities and document the smallest reliable core loop.

    Output: risk map + prioritized bug list
  2. 02 / STABILIZE

    Fix the seams

    Make input, state, animation, camera and AI hand-offs explicit before expanding features.

    Output: testable gameplay baseline
  3. 03 / BUILD

    Implement deliberately

    Add reusable C# systems, adapters and editor tools around clear responsibilities.

    Output: reviewable implementation
  4. 04 / HAND OFF

    Leave a trail

    Document dependencies, setup, known limits and verification steps for the next developer.

    Output: code + evidence + documentation
